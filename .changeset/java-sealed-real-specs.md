`compiler-java` supports `permits` on interface declarations and wraps long type headers, generic arguments, enum constants, comments and call chains the way google-java-format does. `openapi-java` emits integer enums as Java enums, returns a `sealed` interface for multi-status operations, and generates code that compiles and is google-java-format clean for large real-world specs (Stripe, OpenAI, Box, DigitalOcean, Slack, Mux).
